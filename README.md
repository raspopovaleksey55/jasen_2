# jasen55_ — переработанная версия сайта ОРОО «ЦПОИ «Ясень»

Статический сайт организации: восемь страниц, без внешних библиотек и шрифтов.
Это **новый вариант** сайта; прежняя версия живёт в репозитории `jasen55` и отдаётся на домене
`jasen55.ru`. Здесь — версия после разбора по качеству и SEO от 12.10.2026.

## Что изменено против прежней версии

**Содержание**

- **Страница «Отчёты» больше ничего не обещает.** Было: «Годовые отчёты публикуются на этой
  странице. Документы готовятся к размещению» и три пункта «готовится к публикации» — при пустой
  папке документов. Стало: отчёты за 2023–2025 годы высылаются по запросу в течение трёх рабочих
  дней (как и было написано ниже на той же странице), с перечнем того, что в отчёт входит.
- **Исправлена битая ссылка.** Пункт «карточки проектов» вёл на
  `президентскиегранты.рф/public/application/item` — этот адрес отдаёт 404. Теперь ссылка ведёт
  на сайт фонда, а номера заявок остались текстом.
- **В первом экране появилось действие** — «Смотреть фестиваль в фотографиях» (ссылка на группу
  во ВКонтакте). Раньше единственное приглашение стояло в самом конце длинной страницы.
  Кнопку-приглашение для школ («Пригласить класс на урок живой истории») по решению Алексея
  убрали 12.10.2026.

**Поисковики и пересылка ссылок**

- `rel="canonical"` на всех восьми страницах (указывает на `https://jasen55.ru/…`).
- Разметка Open Graph на всех страницах: заголовок, описание, адрес, картинка и её описание.
  Раньше была только на главной.
- Добавлены `robots.txt` и `sitemap.xml`.
- Убран устаревший `meta keywords`.

**Доступность и качество кода**

- Ссылка «Перейти к содержанию» для навигации с клавиатуры.
- Видимый фокус (`:focus-visible`) для ссылок и кнопок, включая тёмные плашки.
- `@media (prefers-reduced-motion: reduce)` — плавная прокрутка отключается по желанию пользователя.
- В таблицах строкам проставлен `scope="row"`.

## Что осталось сделать

1. **Выложить отчёты** в папку `otchety/` и вернуть на страницу настоящие ссылки, когда документы
   будут готовы.
2. **Включить «Enforce HTTPS»** в настройках GitHub Pages: сейчас `http://jasen55.ru/` и
   `https://jasen55.ru/` отвечают одинаково.
3. **Ссылки на карточки проектов ФПГ** — нужен внутренний идентификатор проекта в системе фонда;
   угадать его нельзя, поэтому номера заявок перечислены на странице текстом.
4. **Проверить в браузере** две ссылки, которые не удалось проверить из-за VPN: страница фестиваля
   на `admomsk.gosuslugi.ru` и афиша на `myhistorypark.ru`.
5. **Посмотреть глазами на телефоне.** Ширина 390 px снимком не проверялась: Chrome держит ширину
   макета не меньше 489 px. Горизонтального переполнения нет — замерено скриптом.
